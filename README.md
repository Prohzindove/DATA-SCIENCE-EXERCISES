# DATA SCIENCE EXERCISES-SQL Fundamentals

This folder contains exercises demonstrating my understanding of fundamental SQL concepts and functions. The exercises cover core SQL operations such as SELECT, GROUP BY, ORDER BY, HAVING, and aggregate functions.

I also worked with date and time functions, including converting timestamps between time zones, converting strings to dates, and extracting components such as year, month, and hour. In addition, the exercises demonstrate the use of NULL functions for handling missing values and improving data quality.

The exercises were completed by hand without relying on AI tools. This approach was intentional, allowing me to build a stronger understanding of SQL fundamentals and develop problem-solving skills before applying modern technologies such as AI to support my learning.
